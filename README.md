# Mein Lebensrad – Vollversion

**Tanja Sattelberg · Systemische Beraterin & Coach · [Mein Veränderungsweg](https://veraenderungsweg.de)**

Ein Selbstreflexions-Tool zu acht Lebensbereichen. Es begleitet die Kurse 01–08 von Mein Veränderungsweg: Du schaust, wo du heute stehst, bekommst passende Übungen und Fragen und kannst später sehen, wie sich deine Einschätzung verändert hat.

> **Hinweis:** Coaching- und Selbstreflexionsangebot, kein therapeutisches Angebot. Das Tool ersetzt keine Psychotherapie und keine medizinische Behandlung.

## Die acht Lebensbereiche

Inneres Erleben · Beziehungen · Arbeit · Finanzen · Körper · Entwicklung · Alltag · Lebensfreude

Jedem Bereich ist ein Kurs zugeordnet (Kurs 01 bis Kurs 08, der Körper-Kurs ist Kurs 05a).

## Was das Tool kann

| Reiter | Inhalt |
| --- | --- |
| Mein Start | Lebensrad ausfüllen, Startwerte speichern, Mini-Übung für die zwei niedrigsten Bereiche, erste Reflexionsfragen |
| Kursbegleitung | Pro Bereich: Empfehlung, Kernübung, kleine Übung für heute, Reflexionsfragen und Affirmationen |
| Nach dem Kurs | Lebensrad erneut ausfüllen, Endwerte speichern, Abschluss-Reflexion |
| Mein Wachstum | Vorher-Nachher-Vergleich mit Datum (ein Standortvergleich, kein Nachweis einer Wirkung) |
| Nächster Schritt | Hinweise auf mögliche Begleitung |

## Datenschutz und Technik

- Eine einzelne HTML-Seite, gehostet über GitHub Pages.
- Keine Cookies, kein Tracking, keine externen Dienste. Die Schriften (Cormorant Garamond und Jost) liegen lokal im Repo (`fonts.css` und Ordner `fonts`).
- Deine Werte werden nur im Browser auf deinem Gerät gespeichert (Local Storage). Wenn du die Browserdaten löschst oder das Gerät wechselst, sind sie weg. Texte in den Reflexionsfeldern werden nicht gespeichert.
